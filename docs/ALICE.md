# Голосовая половина: колонка и навык Алисы

Как это работает: служба произносит вопрос на Яндекс-Станции по локальному
протоколу glagol, человек отвечает «Алиса, ответь коду …», навык Диалогов бьёт в
вебхук `/alice/<секрет>`, и ответ уходит той сессии, которая спросила раньше.

## 1. Токен Яндекса

Нужен OAuth-токен со скоупами «Умный дом» (`iot:view`, `iot:control`) — тот же,
что используют интеграции Яндекс-Станции для Home Assistant.

- Если такой токен уже есть на другой машине — переиспользуй его, не выпускай
  новый.
- Иначе человек создаёт приложение на <https://oauth.yandex.ru/client/new>
  (тип «Веб-сервисы», Redirect URI можно
  `https://oauth.yandex.ru/verification_code`), отмечает скоупы «Умный дом» и
  получает токен неявным потоком:
  `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ID приложения>`.
  Токен придёт в адресной строке после `#access_token=`.

**Проверить, годится ли токен** (это единственный надёжный способ — у Яндекса два
разных API, и нам нужен именно glagol):

```bash
node scripts/find-stations.mjs                 # адрес и device_id колонки
curl -s "https://quasar.yandex.net/glagol/token?device_id=<DEVICE_ID>&platform=<PLATFORM>" \
  -H "Authorization: Oauth <ТОКЕН>" | head -c 120
```
`{"status":"ok","token":"…"}` — годится. `401` — токен без нужного скоупа.

Токен кладётся в `.env` как `VOICE_YANDEX_TOKEN` (через `./start.sh --yandex-token=…`).
**В ответ пользователю его не печатать.**

## 2. Колонки

```bash
node scripts/find-stations.mjs            # список: device_id, platform, адрес
node scripts/find-stations.mjs --env      # строки VOICE_STATIONS= и VOICE_STATION=
```

Поиск идёт по mDNS (`_yandexio._tcp`) и работает **только с машины в той же сети**,
что колонки — из контейнера multicast не ходит, поэтому скрипт запускается на хосте,
а служба берёт готовые адреса из `.env`.

Человеческие имена — `VOICE_STATION_NAMES=device_id:имя, device_id:имя`; после
этого колонку можно выбирать словом: `{"station":"кабинет"}`. Сопоставить
device_id с комнатой помогает официальный API умного дома:

```bash
curl -s https://api.iot.yandex.net/v1.0/user/info -H "Authorization: OAuth <ТОКЕН>" \
  | node -e 'let s="";process.stdin.on("data",d=>s+=d).on("end",()=>{const d=JSON.parse(s);
      const rooms=Object.fromEntries((d.rooms||[]).map(r=>[r.id,r.name]));
      for(const x of d.devices||[]) if(x.quasar_info) console.log(x.quasar_info.device_id, "|", x.name, "|", rooms[x.room]);})'
```

Колонка по умолчанию — `VOICE_STATION` (номер, имя или device_id).

**Если служба не в домашней сети** (например, на VPS): она достаёт колонку через
прокси на домашней машине — `pcproxy/`, переменная `VOICE_PC_PROXY`. Установка:
`hostshim`-подобный скрипт `pcproxy/install-windows.ps1` (Windows) или запуск
`pcproxy/proxy.py` руками на macOS/Linux.

## 3. Проверка озвучки

```bash
T=$(sed -n 's/^CLIENT_TOKENS=\([^:]*\).*/\1/p' .env)
curl -s -H "X-Token: $T" http://127.0.0.1:4020/api/voice/stations
curl -s -H "X-Token: $T" -H 'Content-Type: application/json' \
  -X POST http://127.0.0.1:4020/api/voice/say -d '{"text":"проверка","station":"1"}'
```
`{"ok":true,"detail":"<имя колонки>"}` — колонка проговорила. `ok:false` с
`колонок не видно` — не заполнены `VOICE_STATIONS`/прокси; с `401` — токен.

## 4. Навык Алисы (руками в консоли, один раз)

Вебхук должен быть доступен извне по HTTPS с валидным сертификатом, адрес:
`<PUBLIC_URL>/alice/<VOICE_ALICE_SECRET>` (значения — в `.env`).

1. <https://dialogs.yandex.ru/developer> → «Создать навык Алисы».
2. **Название:** «Ответь коду» — фраза активации совпадает с тем, как удобно
   говорить: «Алиса, ответь коду — да».
3. **Примеры запросов:** «Запусти навык» + активационное имя.
4. **Backend → Webhook URL:** адрес выше.
5. **Тип доступа: приватный** — навык не попадёт в каталог и **не требует
   модерации**, публикуется сразу.
6. Категория, имя разработчика, иконка — любые (иконка обязательна, без неё
   кнопка публикации неактивна).
7. «Тестирование» — проверить сразу: пустая фраза → навык читает первый вопрос
   очереди; любой текст → ответ уходит первому в очереди.
8. Нажать «Отправить на модерацию» — для приватного навыка это и есть публикация.

Что понимает навык: пусто / «повтори» / «что там» — читает первый вопрос, не
списывая; «пропусти» — снимает его; «сколько вопросов» — размер очереди; любой
другой текст — ответ первому в очереди.

## Частые причины «колонка молчит»

| Симптом | Причина |
|---|---|
| `колонок не видно` | `VOICE_STATIONS` пуст и прокси не задан; запусти `find-stations.mjs --env` на машине в той же сети |
| `401` от glagol | токен без скоупа «Умный дом» |
| `ok:true`, но тишина | колонка занята другим сценарием или выключен звук; проверь другую колонку через `station` |
| вопрос звучит, ответа нет | навык не опубликован или в вебхуке другой секрет |
| навык отвечает «вопросов нет» | вопрос уже истёк (`ASK_TTL`/`VOICE_TTL_MS`) или его забрала другая сессия |
