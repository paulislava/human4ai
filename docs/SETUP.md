# Развернуть human4ai на любой машине

Одна команда, один контейнер, дальше — служба, которая поднимается сама после
перезагрузки.

## Коротко

```bash
git clone https://github.com/paulislava/human4ai.git
cd human4ai
./start.sh                     # Windows: powershell -File start.ps1
```

Скрипт идемпотентный: запускай сколько нужно. Он проверит Docker, создаст `.env`
(секреты сгенерирует сам, недостающее спросит), найдёт колонки в локальной сети,
поднимет контейнер, дождётся `/api/health`, поставит автозапуск, а затем пропишет
**MCP и скилы** во всех найденных агентов: Claude Code, Codex, OpenClaw и Sokrat
(он обёртка над Codex, поэтому настраивается тем же CLI с его домом —
`CODEX_HOME=~/.sokrat`). Токен MCP попадает и в переменную окружения
`HUMAN4AI_MCP_TOKEN`: Codex умеет bearer только так.

Неинтерактивно:

```bash
./start.sh --non-interactive \
  --telegram-token=123456:AA… --chat-id=318445470 --yandex-token=y0_… \
  --public-url=https://human4ai.example.com --port=4020
```

| Флаг | Зачем |
|---|---|
| `--non-interactive` | ничего не спрашивать (CI, повторная настройка) |
| `--port=` | другой порт на хосте (по умолчанию 4020) |
| `--public-url=` | публичный адрес: нужен вебхуку Алисы и MCP с других машин |
| `--skip-mcp` | не трогать конфиги агентов |
| `--skip-service` | не ставить автозапуск |
| `--skip-stations` | не искать колонки |
| `--rebuild` | пересобрать образ с нуля |
| `--only-agents` | ничего не поднимать: только прописать MCP и скилы агентам |
| `--mcp-token=` | токен для `--only-agents`, если рядом нет `.env` |
| `--agents=` | кому ставить: `claude,codex,sokrat,openclaw`, `all` или `none` |

### Выбор агентов

Без флага скрипт показывает меню и ждёт номера через запятую:

```
    Кому прописать MCP и скилы:
      1) Claude Code
      2) Codex
      3) Sokrat (обёртка над Codex)
      4) OpenClaw
    Номера через запятую (Enter — все, 0 — никому):
```

В списке только те агенты, что найдены на машине; ненайденные показаны отдельно
и выбрать их нельзя. Для скриптов и CI — `--agents=claude,codex` (в PowerShell
`-Agents claude,codex`).

### Подключить агентов на другой машине

Служба одна, а работать с ней хочется с любого ноутбука. Там Docker не нужен:

```bash
./start.sh --only-agents \
  --public-url=https://human4ai.example.com --mcp-token=<MCP_TOKEN из .env службы>
```

Скрипт пропишет MCP и положит скилы во всех найденных агентов: Claude Code,
Codex, OpenClaw, Sokrat.

## Что нужно приготовить

| Что | Зачем | Где взять |
|---|---|---|
| Docker | всё живёт в контейнере | Desktop (macOS/Windows) или `get.docker.com` |
| Токен Telegram-бота | вопросы человеку и капча | `@BotFather` → `/newbot` |
| Публичный HTTPS-адрес | вебхук навыка Алисы | свой домен + nginx/туннель |

`chat_id` спрашивать не нужно: после токена бота установщик сам подключается к
нему и ждёт, пока ты напишешь боту любое сообщение — id берёт оттуда. Если служба
уже запущена, он на это время останавливает контейнер: обновления Telegram
отдаёт только одному потребителю.

Токен Яндекса (нужен лишь для озвучки) выдаёт OAuth в браузере, поэтому
установщик открывает страницу выдачи сам — **своё приложение регистрировать не
надо**: используется публичный `client_id` приложения «Яндекс Музыка», тот же, на
котором работают открытые библиотеки к API Яндекса. Достаточно разрешить доступ и
вставить в консоль адресную строку целиком: токен из неё вытаскивается сам. Своё
приложение при желании подставляется через `YANDEX_OAUTH_CLIENT_ID` в `.env`.

Сразу после ввода токен проверяется запросом к glagol — «не тот скоуп» видно на
месте, а не когда колонка промолчит на первый вопрос.

**Telegram из RU-сети закрыт** — задай прокси, и его будут использовать и
установщик, и служба:

```bash
TELEGRAM_PROXY=http://user:pass@host:port ./start.sh
# либо строкой TELEGRAM_PROXY=… в .env
```

Без Telegram-токена служба работает как разгадыватель капчи и голосовой канал;
без токена Яндекса — только Telegram. Ничто из этого не обязательно для старта.

## Проверить, что живо

```bash
curl -s http://127.0.0.1:4020/api/health
# {"status":"ok","solvers":[…],"asks":true,"voice":true,"voiceQueue":0,"mcp":true}

T=$(sed -n 's/^CLIENT_TOKENS=\([^:]*\).*/\1/p' .env)
curl -s -H "X-Token: $T" http://127.0.0.1:4020/api/voice/stations
curl -s -H "X-Token: $T" -H 'Content-Type: application/json' \
  -X POST http://127.0.0.1:4020/api/voice/say -d '{"text":"проверка"}'
```

## Управление

```bash
docker compose logs -f          # логи
docker compose stop             # остановить
docker compose up -d            # поднять
git pull && ./start.sh          # обновить и перезапустить
```

Автозапуск: Linux — `systemctl status human4ai`, macOS — launchd-агент
`ai.human4ai.compose`, Windows — задача планировщика `human4ai`. Сам контейнер
живёт с политикой `restart: unless-stopped`, служба ОС нужна для случая, когда
Docker стартует позже пользователя.

## Ступени каскада капчи

| Ступень | Что нужно |
|---|---|
| `gigachat` | `GPT2GIGA_BASE_URL` — свой gpt2giga-proxy |
| `claude` | авторизованный `claude` CLI **на хосте** + `bash hostshim/install.sh`, затем `CLAUDE_SHIM_URL`/`CLAUDE_SHIM_TOKEN` в `.env` |
| `human` | токен бота и `chat_id` |

Каждая ступень независима: чего нет — то просто выпадает из каскада, и это видно
в `/api/health`.

## Если служба не в домашней сети

Колонки доступны только по LAN. Когда служба стоит на VPS, доступ в домашнюю сеть
даёт прокси на домашней машине (`pcproxy/`, переменная `VOICE_PC_PROXY`) — см.
[docs/ALICE.md](ALICE.md).
