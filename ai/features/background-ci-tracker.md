# Фоновое ожидание CI

## Назначение

`human4ai-ci-track` отслеживает GitLab pipeline/job или GitHub Actions
run/job фоновым процессом. `human4ai-ci-status` ждёт сохранённый результат,
не выполняя собственные запросы к CI. Обе команды входят в автономный
плагин human4ai-control 0.2.0 и работают вне репозитория.

## Запуск и получение результата

```bash
human4ai-ci-track start --url 'https://git.example.org/group/project/-/pipelines/123' --job-name 'deploy' --cwd '/path/to/repository'
human4ai-ci-status '<id>' --wait-ms 300000
human4ai-ci-track cancel '<id>'
```

Для GitHub передаётся URL вида
`https://github.example.org/owner/repo/actions/runs/456` либо конкретной job.
Хост определяется по URL; `glab`/`gh` используют уже настроенный доступ
к этому хосту. Токены не читаются скриптом и не выводятся.

Статус по умолчанию ждёт до 300000 мс; `--infinite` ждёт без ограничения.
Если окно ожидания истекло, возвращается `in_progress`. Его нужно повторять
с максимальным ожиданием текущего тула до терминального результата.
Отмена отменяет локальное отслеживание.

## Завершение и продолжения

Успех фиксируется только после подтверждения условия. Ошибка, отмена,
блокировка, пропуск/отсутствие целевой job в завершённом CI, итоговый таймаут
и смерть tracker завершают ожидание с явным статусом. Для GitLab учитываются
вложенные downstream и необязательные ветки. Для GitHub учитываются
conclusion run/job и запрос обязательного ручного действия.

State хранится в `~/.human4ai/ci-track`: каталог 0700, файлы 0600, запись
атомарная. `--state-dir` или `HUMAN4AI_CI_DIR` задают отдельный каталог.
Heartbeat обновляется во время I/O. Маркер прерывания запрещает позднему
ответу восстановить терминально остановленное ожидание.

`--on-success` принимает JSON-массив команды и аргументов только для
заранее разрешённого действия. Claim сохраняется до запуска; ошибка записи
после действия не приводит к его повтору. После отмены или истечения
deadline новое действие не запускается. Аргументы продолжения не входят
в публичный результат команды статуса.

## Файлы и проверки

- `plugins/human4ai-control/scripts/ci-track.cjs` — запуск и отмена.
- `plugins/human4ai-control/scripts/ci-status.cjs` — длительное ожидание.
- `plugins/human4ai-control/scripts/lib/` — состояния, провайдеры и worker.
- `scripts/ci-track.cjs`, `scripts/ci-status.cjs` — точки входа репозитория.
- `src/ci-tracker-cli.spec.ts` — реальные дочерние процессы с fake CLI на внешней границе.

Тесты сначала воспроизвели ошибки, включая повтор continuation после EIO,
ложный interrupted при медленном API, неверную обработку optional downstream
и запуск после deadline. После исправления 26 проверок CLI прошли на Node 18;
общие 135 тестов и TypeScript build прошли на Node 22. Реальные завершённые
GitLab job и GitHub run проверены через общий tracker/status. Копия плагина
вне репозитория покрыта проверкой без зависимостей проекта.
